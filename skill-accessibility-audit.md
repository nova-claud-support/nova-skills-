# Accessibility Audit

## Workflow
1. Define pages, user journeys, and input methods in scope.
2. Inspect semantic structure, headings, landmarks, labels, and alternative text.
3. Navigate interactive elements using keyboard only.
4. Check visible focus, logical focus order, and dialog focus handling.
5. Review contrast, zoom, and responsive reflow.
6. Check form instructions, error identification, and status announcements.
7. Use automated scans as supporting evidence, not as a complete audit.
8. Record each issue with location, impact, reproduction, and recommended fix.
9. Re-test after remediation.

## Validation
- [ ] Main tasks can be completed by keyboard.
- [ ] Controls have accessible names and appropriate roles.
- [ ] Focus is visible and predictable.
- [ ] Form errors are understandable.
- [ ] Automated findings are manually reviewed.

## Limitations
An automated scan cannot establish full accessibility conformance. State what was and was not tested.
