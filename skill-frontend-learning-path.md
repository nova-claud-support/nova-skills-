# Frontend Learning Path

## Purpose
Convert a learner's current experience, available time, and goals into a measurable frontend development plan.

## When to use
- Creating beginner-to-advanced learning sequences.
- Selecting projects that demonstrate specific frontend competencies.
- Diagnosing knowledge gaps and planning the next practice milestone.

## When not to use
- When the user asks for a single code fix rather than a learning plan.
- When a formal accredited curriculum or certification decision is required.

## Requirements
- Current skill level, if known.
- Target outcome, such as building websites or interactive web applications.
- Realistic study time and device constraints.

## Workflow
1. Establish the target outcome and starting level without assuming prior knowledge.
2. Assess core areas: semantic HTML, CSS layout, responsive design, JavaScript fundamentals, DOM, accessibility, debugging, and version control.
3. Order topics by dependency; do not introduce advanced tooling before the foundations are understood.
4. Define a small project for each milestone.
5. Give each project acceptance criteria and a self-review checklist.
6. Include spaced review and deliberate practice of previously learned concepts.
7. Reassess using a practical task rather than confidence alone.
8. Adjust the next milestone based on demonstrated results.

## Suggested milestones
1. Semantic page structure and forms.
2. CSS selectors, box model, Flexbox, and Grid.
3. Responsive layouts and accessible navigation.
4. JavaScript values, functions, arrays, and objects.
5. DOM updates, events, and form handling.
6. Fetching and displaying public sample data safely.
7. Component thinking, testing, and maintainable project structure.
8. Performance, accessibility, and production readiness.

## Validation
- [ ] Each milestone has a concrete deliverable.
- [ ] Prerequisites are respected.
- [ ] Projects test the stated competencies.
- [ ] Time estimates are realistic and adjustable.
- [ ] Progress is based on completed work, not time spent alone.

## Safety and privacy
Do not request passwords, API secrets, private account data, or unnecessary personal details. Use local sample data for exercises.
