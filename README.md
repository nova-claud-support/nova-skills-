# NOVA SKILLS

مكتبة مهارات عملية للبرمجة والتطوير والذكاء الاصطناعي والتصميم والاختبار والأمن السيبراني الدفاعي.

<blockquote>
<strong>421 مهارة مستقلة</strong><br/>
جميع المهارات معروضة في فهرس واضح، ويمكن فتح كل مهارة وقراءة ملفها مباشرة.
</blockquote>

## تصفح المهارات

**[افتح فهرس جميع المهارات الـ421](SKILLS_CATALOG.md)**

الفهرس مرتب أبجدياً، وكل اسم مهارة مرتبط بملف Markdown الخاص بها.

## طريقة الاستخدام

1. افتح المهارة المطلوبة من الفهرس.
2. اقرأ محتواها أو انسخه إلى نموذج الذكاء الاصطناعي.
3. اكتب المهمة والسياق والقيود بوضوح.
4. اطلب من النموذج اتباع خطوات المهارة والتحقق من النتائج.

لا تحتاج المهارات إلى ملف تفعيل خاص؛ كل مهارة ملف Markdown مستقل. التحميل التلقائي وتشغيل الأدوات يعتمدان على التطبيق والصلاحيات المتاحة.

## بنية المكتبة

- `skill-*.md`: ملفات المهارات.
- `agent-*.md`: أدوار المراجعة والتخصص.
- `reference-*.md`: قوائم تحقق ومراجع عملية.
- `license-*.md`: إشعارات التراخيص المطلوبة.
- `SKILLS_CATALOG.md`: الفهرس الكامل المرتب لجميع المهارات.

## التوافق

المهارات مكتوبة بصيغة Markdown ويمكن تقديمها إلى أي نموذج يستطيع قراءة النص. لا يعني ذلك أن كل تطبيق يحمّلها تلقائياً أو يمتلك الأدوات نفسها.

## التراخيص والنزاهة

تحتفظ المكتبة بإشعارات حقوق النشر والتراخيص المطلوبة. لا تُنسب المواد المرخّصة لطرف ثالث إلى مؤلف آخر، ويجب احترام شروط الترخيص عند إعادة الاستخدام.
