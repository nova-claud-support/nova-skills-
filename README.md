# NOVA SKILLS

مكتبة موحّدة تضم **421 ملف مهارة** بصيغة Markdown، إضافة إلى أدلة ومعايير وقوائم مراجعة.

## طريقة الاستخدام

1. افتح ملف المهارة الذي يطابق مهمتك.
2. انسخ محتواه أو أرفقه للمساعد الذكي.
3. اكتب المهمة وحدودها والملفات أو المعلومات المسموح استخدامها.
4. اطلب تنفيذ الخطوات والتحقق من النتائج مع توضيح ما تم وما لم يتم.

لا تحتاج الملفات إلى أمر تفعيل خاص داخل هذه المكتبة؛ إنها تعليمات Markdown مستقلة. أما التحميل التلقائي أو تشغيل الأدوات فيعتمد على التطبيق والصلاحيات المتاحة، وليس على ملف Markdown وحده.

## التنظيم

جميع الملفات موجودة في المستوى الرئيسي للمستودع دون مجلدات. أسماء الملفات واضحة ومسبوقة بنوعها:
- `skill-*.md`: المهارات.
- `agent-*.md`: أدوار المراجعة والتخصص.
- `reference-*.md`: قوائم التحقق والمراجع العملية.
- `license-*.md`: إشعارات التراخيص المطلوبة.

راجع `SKILLS_CATALOG.md` للعثور على المهارة المناسبة.

## التوافق

المهارات مكتوبة بصيغة Markdown ويمكن تقديمها إلى أي نموذج يستطيع قراءة النص. لا يعني ذلك أن كل تطبيق يحمّلها تلقائياً أو يمتلك الأدوات نفسها.

## النزاهة والتراخيص

تم تنسيق المكتبة وتجميعها لتكون سهلة الاستخدام. تبقى إشعارات حقوق النشر والتراخيص المطلوبة محفوظة في ملفاتها؛ ولا يجوز وصف محتوى مرخّص لطرف ثالث بأنه مؤلّف بالكامل من NOVA SKILLS.
