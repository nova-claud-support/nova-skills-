# UI/UX Design

## Purpose
Turn product requirements into coherent user flows and interface specifications.

## Workflow
1. Identify user goals, primary tasks, constraints, and device context.
2. Map the key user journey and note decision points and failure states.
3. Prioritize information hierarchy and make primary actions clear.
4. Define reusable components, spacing, typography, color roles, and interaction states.
5. Design loading, empty, success, error, and disabled states.
6. Ensure responsive behavior and accessibility from the beginning.
7. Review the flow against realistic tasks and revise confusing steps.
8. Document component behavior and edge cases for implementation.

## Validation
- [ ] A user can identify the primary action quickly.
- [ ] Navigation and terminology are consistent.
- [ ] Forms explain errors and preserve useful input.
- [ ] Keyboard focus and readable contrast are considered.
- [ ] Empty, loading, and failure states are specified.

## Output
Provide user flows, screen descriptions, component rules, and unresolved assumptions. Do not claim user research was conducted unless it actually was.
