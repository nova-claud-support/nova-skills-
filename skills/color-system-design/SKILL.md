# Color System Design

## Purpose
Create coherent semantic color palettes with accessible contrast and reusable tokens.

## Workflow
1. Identify the user goal, page context, target devices, and existing design system.
2. Review the current stack and reuse installed dependencies before adding new ones.
3. Define the visual behavior, interaction states, responsive behavior, and accessibility fallback.
4. Implement with semantic HTML and maintainable CSS/components; keep motion purposeful and performant.
5. Validate keyboard navigation, touch behavior, reduced motion, contrast, responsive layouts, and runtime performance.

## Quality checks
- The interface remains usable when animation is disabled.
- Content and controls are readable and accessible.
- Motion does not block navigation or cause layout shifts.
- Colors and typography are consistent across states and themes.
- The design feels intentional and specific to the product, not like an interchangeable template.

## Safety and integrity
Do not fabricate testimonials, ratings, customer counts, or product claims. Do not imitate a specific brand deceptively. Prefer original visual direction and disclose material limitations when relevant.

## Output
Provide the implementation, explain important design decisions, and list validation performed and any remaining limitations.
