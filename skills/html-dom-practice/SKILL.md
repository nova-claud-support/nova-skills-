# HTML DOM Practice

## Purpose
Create progressively challenging browser exercises that develop practical HTML, CSS, and JavaScript skills.

## When to use
- Designing hands-on frontend learning tasks.
- Practising DOM selection, events, forms, and dynamic rendering.
- Turning a concept into a small, testable browser project.

## When not to use
- When the task requires backend services or production infrastructure.
- When a learner needs a complete framework-specific curriculum.

## Requirements
- A modern browser.
- A text editor.
- A clear learning objective and an appropriate difficulty level.

## Workflow
1. Define one primary concept and no more than two supporting concepts.
2. State the expected behavior before presenting code.
3. Start with semantic HTML and accessible labels.
4. Add the minimum CSS needed for readable layout and responsive behavior.
5. Implement JavaScript with clear DOM queries and event listeners.
6. Include empty, invalid, and boundary states where relevant.
7. Ask the learner to modify one feature independently.
8. Provide a short explanation of the solution and common mistakes.

## Exercise patterns
- Interactive counter with increment, decrement, and reset.
- Form validation with inline feedback.
- Searchable list rendered from a local array.
- Tabs or accordion with keyboard-accessible controls.
- Theme toggle that respects readable contrast.

## Validation
- [ ] HTML uses appropriate semantic elements.
- [ ] Interactive controls work with keyboard and pointer.
- [ ] Labels and feedback are understandable.
- [ ] No uncaught console errors occur.
- [ ] Layout remains usable on narrow screens.

## Safety and privacy
Use synthetic data. Do not collect or transmit personal information in beginner exercises.

## Notes
Keep each exercise self-contained and avoid adding dependencies unless the learning goal requires them.
